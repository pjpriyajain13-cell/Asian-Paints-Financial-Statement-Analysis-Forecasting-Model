# Asian Paints Financial Statement Analysis & Forecasting Model

## Project Overview

This project analyzes the financial performance of Asian Paints Ltd. using 10 years of historical financial data. The objective is to evaluate the company's growth, profitability, operational efficiency, and future performance through financial analysis and forecasting techniques.

## Objectives

* Analyze historical financial statements.
* Evaluate profitability and growth trends.
* Perform ratio and common-size analysis.
* Forecast future financial performance.
* Visualize insights through dashboards and charts.

## Key Analyses Performed

### Financial Statement Analysis

* Income Statement Analysis
* Balance Sheet Analysis
* Historical Trend Analysis

### Ratio Analysis

* Revenue Growth Rate
* EBITDA Growth Rate
* EBIT Growth Rate
* Net Profit Growth Rate
* Gross Margin
* EBITDA Margin
* EBIT Margin
* Net Profit Margin

### Common Size Analysis

* Revenue as a percentage base
* Expense structure analysis
* Profitability comparison across years

### Forecasting Model

Built a 5-year forecasting model for:

* Sales Revenue
* EBITDA
* Earnings Per Share (EPS)
